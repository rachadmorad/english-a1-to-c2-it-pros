# 🎮 Word Games (5–10 minutes each)

1. **Hangman — IT words:** router, server, laptop, password, keyboard, firewall. Guess letters using the English alphabet names (*Is there an "ay"?*).
2. **20 Questions:** Think of an IT object. Your partner asks *Is it big? Is it on the desk? Does it have a screen?* (max 20).
3. **Odd One Out:** Say 4 words; find the different one. (*mouse – keyboard – chair – monitor*)
4. **Word Snake:** Say a word; the next word starts with the last letter (*router → router → r...*).
5. **Memory Match:** Write English words and pictures (emoji) on 16 cards. Turn 2 at a time. Say the word when you match.
6. **Sentence Dice:** Roll two dice. Use the tables to build a sentence.

| Die 1 | Subject | | Die 2 | Verb phrase |
|---|---|---|---|---|
| 1 | I | | 1 | restart the server |
| 2 | She | | 2 | check tickets |
| 3 | We | | 3 | reset passwords |
| 4 | Omar | | 4 | monitor the network |
| 5 | They | | 5 | answer calls |
| 6 | The firewall | | 6 | block attacks |

Say it **affirmative, negative and as a question** (*She checks tickets. She doesn't check tickets. Does she check tickets?*)
