# Unit 7 — In the server room

## 2. Lesson / الدرس

### 1. There is / There are — "يوجد"
Use it to say that something **exists** in a place.

| | Singular | Plural |
|---|---|---|
| + | **There is** a laptop on the desk. | **There are** three racks. |
| − | **There isn't** a window. | **There aren't** any windows. |
| ? | **Is there** a printer? | **Are there** any servers? |
| Short | Yes, there **is**. / No, there **isn't**. | Yes, there **are**. / No, there **aren't**. |

- Arabic has no verb here; in English you need **there is/are** (not ~~in the room a server~~).
- Contraction: **there's** a server. (No contraction for *there are* in writing.)

### 2. some / any / a lot of
| | Use | Example |
|---|---|---|
| **some** | positive | There are **some** cables. |
| **any** | negative & questions | There aren't **any** windows. Are there **any** servers? |
| **a lot of** | many | There are **a lot of** cables. |

### 3. Prepositions of place / حروف الجر
```
        [ SHELF ]           in front of  ▶  [ RACK ]
        [ RACK ]  between  [ RACK ]
   on  ⬆ desk ⬇  under
```
| Preposition | Meaning | Example |
|---|---|---|
| **in** | inside | The USB drive is **in** the box. |
| **on** | on the top of | The laptop is **on** the desk. |
| **under** | below | The box is **under** the desk. |
| **next to** | beside | The extinguisher is **next to** the door. |
| **between** | in the middle of 2 | The router is **between** two racks. |
| **in front of** | before | The desk is **in front of** the rack. |
| **behind** | at the back of | The cable is **behind** the rack. |

### 4. Where is...? / Where are...?
**Where is** the router? — It's **on** the shelf.  |  **Where are** the keys? — They're **in** the cabinet.

## 3. Watch out! Common mistakes for Arabic speakers / انتبه

| ❌ Wrong | ✅ Right | Why / لماذا |
|---|---|---|
| In the room a server. | **There is a server in the room.** | لا بد من there is / there are. |
| There is three racks. | **There are three racks.** | جمع → are. |
| Is there some servers? | **Are there any servers?** | في السؤال نستخدم any. |
| The laptop is in the desk. | **The laptop is on the desk.** | على السطح = on. |

## 4. 🎧 Dialogue — Looking for the router

**Omar:** Sara, where is the spare router?  
**Sara:** It's in the cabinet, next to the door.  
**Omar:** Is there a box in the cabinet?  
**Sara:** Yes, there is. There are some cables in the box.  
**Omar:** Are there any USB drives?  
**Sara:** No, there aren't. There's one under the desk.  
**Omar:** Thanks! Is the fire extinguisher near the door?  
**Sara:** Yes, it is.  

🇸🇦 *عمر يبحث عن الراوتر الاحتياطي. سارة تخبره أنه في الخزانة بجانب الباب.*

**How to use it:** (1) Listen without reading. (2) Listen and read. (3) Read aloud with a partner (shadowing). (4) Cover one side and say your lines from memory.

**3.** There ___ any cables. (no)  
a) isn't  b) don't  c) aren't

a) in front  b) on  c) under

**5.** The laptop is ___ the desk. (top)  
a) in  b) on  c) under

**6.** There are ___ servers. (positive)  
a) a  b) any  c) some

**7.** Where's the router? It's ___ two racks.  
a) between  b) next  c) on

**8.** Which is correct?  
a) It has a server.  b) There is a server.  c) There are a server.
