# Level A1 — Beginner / المستوى المبتدئ

By the end of A1 you can introduce yourself, understand simple work phrases, describe your desk, routine and room, ask for help and handle a very simple help desk call.

| Unit | Topic | Main grammar | Key IT words |
|---|---|---|---|
| [1](unit-01-hello.md) | Hello! I'm an IT technician | to be (I/you/he/she) | technician, help desk, user |
| [2](unit-02-my-desk.md) | This is my desk | to be, a/an, this/that, plurals | laptop, mouse, router, server |
| [3](unit-03-numbers-time.md) | Numbers, time and tickets | numbers, time, at/on/in | IP address, ticket, phone number |
| [4](unit-04-my-team.md) | My team and my things | have/has, possessives, 's | account, badge, license |
| [5](unit-05-work-day.md) | My work day | present simple (I/you/we/they) | log in, restart, update |
| [6](unit-06-he-fixes.md) | She fixes computers | present simple (he/she/it) | firewall, antivirus, backup |
| [7](unit-07-server-room.md) | In the server room | there is/are, prepositions | rack, server room, cabinet |
| [8](unit-08-can-can-t.md) | I can help you | can / can't | reset password, connect, access |
| [9](unit-09-right-now.md) | What are you doing? (right now) | present continuous, imperative | click, press, error message |
| [10](unit-10-help-desk-call.md) | Help desk call (Wh- questions) | Wh- questions, help desk call | ticket, priority, status, VPN |
