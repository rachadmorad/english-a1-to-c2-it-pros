# Unit 9 — What are you doing? (right now)
### ماذا تفعل الآن؟

> ⏱️ Time: 5–6 study sessions of 45 minutes  |  🎧 Audio script: `audio-scripts/unit-09.txt`

## 🎯 Goals / الأهداف
- Say what is happening now
- Use present continuous (am/is/are + -ing)
- Give instructions with the imperative
- Read simple error messages

## 2. Lesson / الدرس

### 1. Present continuous = happening NOW / المضارع المستمر
**Form:** am / is / are + verb**-ing**

| Pronoun | to be | Example |
|---|---|---|
| I | **am** | I **am** update**ing** the server. (I'm updating) |
| he / she / it | **is** | The server **is** restart**ing**. |
| you / we / they | **are** | We **are** wait**ing**. |

- **Negative:** The scan **isn't** running. I'**m not** working.
- **Question:** **Is** the update download**ing**? — Yes, it **is**. / **What are** you do**ing**?
- **Now words:** now, at the moment, right now, today.

### 2. Spelling of -ing
| Rule | Example |
|---|---|
| most verbs: + ing | work → work**ing**, install → install**ing** |
| ends in silent **e**: drop e | make → mak**ing**, close → clos**ing** |
| short CVC: double last letter | run → run**n**ing, stop → stop**p**ing |

### 3. Simple vs continuous
| Present simple (habit) | Present continuous (now) |
|---|---|
| I **check** email every day. | I'**m checking** email now. |
| The server **restarts** on Friday. | The server **is restarting**. |

### 4. Imperative — instructions / الأمر
Use the **base verb**, **no subject**. Negative: **Don't** + verb.
- **Click** Start. **Type** your username. **Wait** two minutes.
- **Don't** turn off the computer. **Don't** share your password.
- Polite: **Please** restart your laptop.

### 5. Reading error messages
| Message | Meaning |
|---|---|
| Access denied | لا يوجد إذن دخول |
| File not found | الملف غير موجود |
| Connection failed | فشل الاتصال |
| Wrong password | كلمة المرور خاطئة |

## 3. Watch out! Common mistakes for Arabic speakers / انتبه

| ❌ Wrong | ✅ Right | Why / لماذا |
|---|---|---|
| I working now. | **I am working now.** | نحتاج am/is/are. |
| The server restarting. | **The server is restarting.** | is + -ing. |
| He is work. | **He is working.** | الفعل + ing. |
| Not turn off the computer. | **Don't turn off the computer.** | النهي = Don't + فعل. |

## 4. 🎧 Dialogue — Slow laptop

**User:** My laptop is very slow.  
**Sara:** OK. What are you doing now?  
**User:** I'm opening my email. And a video is playing.  
**Sara:** Is an update downloading?  
**User:** Yes, it is.  
**Sara:** Please wait five minutes. Don't turn off the laptop.  
**User:** OK. Is it working now?  
**Sara:** Yes, it's running fast now. Thank you for waiting.  

🇸🇦 *حاسوب المستخدم بطيء لأن تحديثًا يتم تنزيله. سارة تطلب منه الانتظار وعدم إطفاء الجهاز.*

**How to use it:** (1) Listen without reading. (2) Listen and read. (3) Read aloud with a partner (shadowing). (4) Cover one side and say your lines from memory.
