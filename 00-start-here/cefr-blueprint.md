# CEFR Blueprint — your map from A1 to C2

The **CEFR** (Common European Framework of Reference) describes 6 levels. Times below are **rough** guided-study estimates (cumulative) from common guidance; they vary a lot between people.

| Level | Name | Approx. total hours | You can... (IT context) |
|---|---|---|---|
| **A1** | Beginner | ~90–100 | Introduce yourself, name IT objects, give simple info, ask for simple help |
| **A2** | Elementary | ~180–200 | Handle simple help desk calls, read short tickets, write short messages |
| **B1** | Intermediate | ~350–400 | Explain a problem, write incident summaries, follow clear technical talk |
| **B2** | Upper-Intermediate | ~500–600 | Work in English daily, read advisories/documentation, join meetings |
| **C1** | Advanced | ~700–800 | Discuss complex topics fluently, write audits, present to managers |
| **C2** | Mastery | ~1000+ | Understand almost everything; precise, natural, professional English |

## Honest advice about the 6-month goal
- With **≈5 hours/week for 24 weeks (≈120 hours)** you can realistically **finish A1 solidly and start A2**.
- C2 is a multi-year goal. This repo is built **level by level**, so you always have a clear next step.
- Daily short practice beats occasional long study.

## A1 "can-do" checklist (tick when true)
- [ ] I can greet, say goodbye and introduce myself
- [ ] I can name 40 IT objects and 20 IT verbs
- [ ] I can say numbers, times, IP addresses and ticket numbers
- [ ] I can describe my daily routine and my room
- [ ] I can say what I can and can't do, and ask for help politely
- [ ] I can make and answer simple questions (what/where/who/when/why/how)
- [ ] I can follow a 6-step help desk call script
