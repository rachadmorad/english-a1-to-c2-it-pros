# 6-Month Study Plan (24 weeks) / خطة 6 أشهر

**Time:** 5 sessions/week (45–60 min) + 10 min Anki daily. If you have less time, keep the order but stretch the weeks.

| Weeks | Focus | Goal |
|---|---|---|
| 1 | Placement test, set up Anki, pronunciation guide | Know your start point |
| 1–2 | **Unit 1** — Hello! | Introduce yourself; spell names |
| 3–4 | **Unit 2** — My desk | Name IT objects; this/that |
| 5–6 | **Unit 3** — Numbers & time | Read IPs and tickets |
| 7–8 | **Unit 4** — My team | have/has, possessives |
| 9–10 | **Unit 5** — Work day | Present simple |
| 11 | Review Units 1–5 + **Progress Test 1** (≥ 80%) | Check |
| 12–13 | **Unit 6** — She fixes computers | he/she/it |
| 14 | **Unit 7** — Server room | there is/are, prepositions |
| 15–16 | **Unit 8** — I can help you | can / can't |
| 17–18 | **Unit 9** — Right now | Present continuous, instructions |
| 19–20 | **Unit 10** — Help desk call | Wh- questions |
| 21 | Review all units, redo weak exercises | Consolidate |
| 22 | **A1 Final Exam** + record the Unit 10 roleplay | Level check |
| 23–24 | Free listening (30 min/day) + retell dialogues + start A2 (when available) | Fluency |

## Weekly checklist
- [ ] 5 sessions done (Learn / Practice / Listen / Speak / Test)
- [ ] 7 days of Anki
- [ ] Mini-quiz score written down: ____/8
- [ ] 5 mistakes added to my notebook

## Monthly self-check (record yourself)
Month 1: introduce yourself (30 s) · Month 2: describe your desk (1 min) · Month 3: your routine (1 min) · Month 4: a help desk roleplay · Month 5–6: talk about your day for 2 minutes without stopping.
