# 🇺🇸 English for IT & Cybersecurity — A1 → C2 (Arabic speakers)
### الإنجليزية لمجال تقنية المعلومات والأمن السيبراني — من A1 إلى C2 (للناطقين بالعربية)

A free, structured, **private-center-style** course. Every lesson is explained in **English with Arabic help**, uses **American English**, and practices with **real IT / cybersecurity situations** (help desk tickets, asset lists, vulnerability reports, error messages).

> ✅ **Available now: Level A1 complete (10 units).**  🔜 A2 → C2 follow the same structure (see `ROADMAP.md`).
> ⚠️ Unofficial study resource. Not affiliated with any exam board. Levels follow the CEFR (Council of Europe).

## What's inside
| Folder / file | What it is |
|---|---|
| 📍 `00-start-here/` | How to use the repo, CEFR blueprint, **placement test**, **6-month study plan** |
| 📚 `levels/A1/` | **10 units**: vocabulary with images/emoji and Arabic, clear lesson, Arabic-speaker mistakes, dialogue, exercises, game, quiz, answer key |
| 🎧 `audio-scripts/` + `tools/` | Dialogue scripts + a tiny tool to create MP3s (American voice) |

| 📝 `practice-tests/` | Progress test (25 Q) and **A1 final exam (51 Q)** with answer keys |
| 🗂️ `flashcards/a1-anki-deck.tsv` | 160 Anki cards (word + Arabic + IT example) |
| ⚡ `cheatsheets/` | Grammar one-pager, top mistakes for Arabic speakers, pronunciation guide, help desk phrases |
| 🎲 `games/` | Board game "Help Desk Adventure", word games |
| 📊 `datasets/` | Fake IT data (tickets, assets, vulnerabilities) used for reading practice |

## Quick start (10 minutes)
1. Do `00-start-here/placement-test.md` → know where to start.
2. Read `00-start-here/how-to-use.md` and `study-plan-6-months.md`.
3. Open `levels/A1/README.md` and start Unit 1.
4. Import `flashcards/a1-anki-deck.tsv` into Anki (File → Import). Review 10 minutes **every day**.

## Every unit has the same 8 steps (like a private center)
1. Vocabulary (with pictures) → 2. Lesson → 3. Common mistakes → 4. Dialogue (listen + shadow) → 5. Practice → 6. Speak & write → 7. Game → 8. Mini-quiz
