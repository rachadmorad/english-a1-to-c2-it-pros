# A1 Grammar Cheat Sheet (one page)

| Topic | Rule | Example |
|---|---|---|
| **to be** | I **am** · he/she/it **is** · you/we/they **are** | She **is** an engineer. |
| **a / an** | a + consonant sound · an + vowel sound | **a** router, **an** IT manager |
| **plural** | +s · +es (box, switch) · y→ies · mouse→mice | cables, boxes, batteries |
| **this/that** | this/these = near · that/those = far | **These** are my cables. |
| **have/has** | I/you/we/they **have** · he/she/it **has** | She **has** a badge. |
| **possessives** | my, your, his, her, our, their, its · *'s* | **Omar's** laptop |
| **present simple** | I/you/we/they + verb · he/she/it + **verb-s** | He **fixes** printers. |
| **negative** | don't / **doesn't** + base verb | She **doesn't work**. |
| **question** | Do / **Does** + subject + base verb? | **Does** he work here? |
| **frequency** | always, usually, often, sometimes, never (before verb, after *be*) | I **never** share my password. |
| **there is/are** | There **is** + singular · There **are** + plural | There **are** three racks. |
| **prepositions** | in, on, under, next to, between, in front of, behind | The box is **under** the desk. |
| **can / can't** | can + base verb (no s, no to) | She **can** reset passwords. |
| **present continuous** | am/is/are + verb-**ing** (now) | The server **is restarting**. |
| **imperative** | base verb · Don't + verb | **Click** Start. **Don't** shut down. |
| **Wh- questions** | Wh- + do/does/is/are/can + subject + verb | **Where is** the printer? |
| **time** | at 9:00 · on Monday · in June | The meeting is **at** 9:30 **on** Monday. |
