# Roadmap / خارطة الطريق

| Level | Status | Focus (IT & cyber themes) |
|---|---|---|
| **A1** | ✅ Done | Introductions, desk & office, numbers/time, routine, help desk basics |
| **A2** | 🔜 Next | Past simple, comparatives, future (going to), countable/uncountable, writing a short ticket note, reading a simple alert |
| **B1** | ⏳ | Present perfect, first conditional, passive, writing incident summaries, phone calls with users |
| **B2** | ⏳ | Reported speech, second/third conditional, reading CVE advisories, meetings, emails to management |
| **C1** | ⏳ | Advanced grammar, security policies, audit reports, presentations, negotiation |
| **C2** | ⏳ | Nuance, style, academic/professional writing, conference talks |

The datasets in `datasets/` grow with the levels (tickets → incident reports → vulnerability reports).
